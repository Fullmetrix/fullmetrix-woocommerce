# Fullmetrix for WooCommerce

Official Fullmetrix plugin for WooCommerce. It connects your store to [Fullmetrix](https://fullmetrix.com), the analytics, segmentation and marketing platform for ecommerce.

Compatible with WordPress 6.2 or later, PHP 7.4 or later.

## Installation

1. Install the plugin from the [WordPress plugin directory](https://wordpress.org/plugins/fullmetrix/) or upload the ZIP from the [releases](https://github.com/Fullmetrix/fullmetrix-woocommerce/releases).
2. Activate it, then open WooCommerce, then Fullmetrix.
3. Enter the connection code shown in Fullmetrix.
